# TextCorrection (錯字app)

TextCorrection是一個macOS應用程式，專門用於偵測並糾正中文文本中的錯別字和常見寫作錯誤。

## 功能特點

- 即時文本糾正和建議
- 一鍵式修正功能
- 支援繁體中文
- 系統級別整合，可在各種應用程式中使用
- 客製化偏好設定，適應個人需求

- Xcode 14.0+
- Swift 5.5+
