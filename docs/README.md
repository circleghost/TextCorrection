# 文件文檔目錄

這個目錄包含與「TextCorrection」(錯字app) 專案相關的所有開發文檔和技術資料。

## 目錄結構

- **根目錄**:
  - `CHANGELOG.md`: 版本更新記錄
  - `SCRATCHPAD.md`: 開發筆記和臨時想法
  - `SwiftUI-Migration.md`: SwiftUI遷移相關指南
  - `優化總結.md`: 效能和代碼優化的總結

- **architecture/**:
  - `ARCHITECTURE.md`: 應用程式架構設計文檔

- **development/**:
  - `CORE_FUNCTIONS.md`: 核心功能描述
  - `DEPENDENCIES.md`: 專案依賴說明
  - `DEVELOPMENT_SETUP.md`: 開發環境設置指南
  - `STATE_MANAGEMENT.md`: 狀態管理架構
  - `TESTING_STRATEGY.md`: 測試策略和方法

- **technical/**:
  - `APPSTATE_ACTOR_REFACTOR.md`: AppState Actor重構指南

## 使用指南

請參考這些文檔來了解專案架構、設置開發環境、以及貢獻代碼。如有新的文檔需要添加，請遵循現有的目錄結構。
